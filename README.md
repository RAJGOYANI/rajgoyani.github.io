## Publish with GitHub Pages

1. Create a new public repository on GitHub named **`rajgoyani.github.io`**
   — this gives you the URL `https://rajgoyani.github.io/`.
2. Upload every file in this folder (drag-and-drop on the repository page, or push with git).
3. In the repository go to **Settings → Pages**, set **Source** to *Deploy from a branch*,
   branch **main**, folder **/ (root)**, and save.
4. Wait about a minute, then open `https://rajgoyani.github.io/`.

Using a different repository name (e.g. `portfolio`) also works; the site is then served at
`https://rajgoyani.github.io/portfolio/`.

## Updating
